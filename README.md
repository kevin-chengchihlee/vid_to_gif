# Video to GIF — local tool

Double-click **Start Video to GIF.command**. Your browser will open the tool at
`http://127.0.0.1:8765`.

Everything runs locally. Videos are never uploaded, and the tool does not need
an internet connection.

If macOS blocks the launcher the first time, right-click it, choose **Open**, and
then confirm **Open**.

Keep the Terminal window open while using the tool. Close it or press Control-C
to stop the local server.
