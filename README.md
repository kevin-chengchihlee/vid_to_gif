# Yerp — Video to GIF

A private, in-browser video-to-GIF converter. Videos are processed locally and
are never uploaded.

## Use online

The GitHub Pages site is deployed from `dist/` after pushes to `main`:

https://kevin-chengchihlee.github.io/vid_to_gif/

## Use locally on macOS

Double-click **Start Video to GIF.command**. Your browser will open the tool at
`http://127.0.0.1:8765`.

Keep the Terminal window open while using the tool. Close it or press Control-C
to stop the local server.

If macOS blocks the launcher the first time, right-click it, choose **Open**, and
then confirm **Open**.
